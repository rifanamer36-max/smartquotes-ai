# SmartQuotes AI 💡

An AI-powered microservice and web application that analyzes text quotes to detect sentiment and categorize them automatically using Natural Language Processing (NLP).

## 🚀 Features
- **Real-time Sentiment Analysis:** Evaluates the tone of any quote.
- **Auto-Categorization:** Tags text as Inspirational, Positive, Reflective, or Neutral.
- **RESTful API Endpoint:** Lightweight Flask server serving analysis endpoints.
- **Clean UI:** Responsive dashboard built with Tailwind CSS.

## 🛠️ Tech Stack
- **Backend / AI:** Python, Flask, TextBlob, Flask-CORS
- **Frontend:** HTML5, JavaScript (Fetch API), Tailwind CSS
